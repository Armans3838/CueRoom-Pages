# What's My Cue? Pages

Public home, privacy, terms, and support pages for the iPhone app What's My Cue? (formerly Cue Room), version 2.0. The repository and its address keep the old name so existing links stay valid. The pages are generated in the app repository by `Scripts/build-legal-pack.py --public-only` from the in-app legal text.

- Privacy: `https://armans3838.github.io/CueRoom-Pages/privacy.html`
- Terms: `https://armans3838.github.io/CueRoom-Pages/terms.html`
- Support: `https://armans3838.github.io/CueRoom-Pages/support.html`
